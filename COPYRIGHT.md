## Ownership

PrintBit was conceived, designed, and developed as a capstone project by
its contributors. The project encompasses:

- **Software** — The Node.js/Express.js/TypeScript backend, Socket.IO
  real-time layer, SQLite data store, frontend HTML/CSS/TypeScript kiosk UI,
  PowerShell deployment scripts, and all supporting utilities.
- **Firmware** — ESP32 for WiFiManager captive portal,
  coin acceptor control, and hardware serial communication.
- **Documentation** — All Markdown documents, architectural diagrams, issue
  specifications, flow charts, and design assets in this repository.
- **Branding** — The "PrintBit" name, logo, and associated visual identity.
