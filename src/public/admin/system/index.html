Replacement SOP

Quick checklist for safe printer swap.

  1. 1
    Install device and vendor driver Use official installer or Device Manager.
  2. 2
    Set as Windows default printer Bluetooth & devices → Printers & scanners.
  3. 3
    Run Re-detect Printer Verify printer name, driver, and connection.
  4. 4
    Run Send Test Page Confirm the kiosk can print before going live.
